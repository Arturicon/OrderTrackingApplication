СТЕК:
Backend (C# / .NET Core): C#, ASP.NET Core, Entity Framework Core, NUnit, Moq
База данных: PostgreSQL
Брокер сообщений: RabbitMQ
Реалтайм: SignalR
Frontend (TypeScript / React): TypeScript, React, Zustand
Связь и интеграция: REST API, WebSockets (SignalR), Очереди сообщений (RabbitMQ)

ЗАПУСК:
1. Скачайте файлы проекта на компьютер.
2. Включите Docker.
3. Откройте консоль в папке решения.
4. Выполните команду: docker-compose up -d.
5. Фронтенд будет доступен по адресу: http://localhost:3000/.

ТЕСТИРОВАНИЕ:
1. При создании заказа подписка на его обновления оформляется автоматически.
2. Управлять подпиской можно на странице заказа.
3. Смотреть уведомления можно, нажав на колокольчик справа сверху.
4. Чтобы увидеть автообновление статуса, нужно подписаться на обновления заказа, а затем воспользоваться тестовым API по адресу: {host}/api/Orders/UpdateOrderStatus. В параметрах передайте ID заказа и название статуса на английском языке.
